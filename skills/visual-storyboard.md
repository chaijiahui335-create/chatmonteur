# Visual Storyboard Skill — Chinese Talking-Head Short Video

## Mission

Turn a spoken script into a visual story before rendering. Do not treat the transcript as a caption file. For each semantic beat, decide what the viewer should see, what text should be emphasized, and whether the speaker, an image, a video insert, a screenshot, or a composed layout best communicates the idea.

## Required planning output

For every semantic segment, produce:

- `start` / `end`
- spoken meaning
- role: hook / problem / point / example / evidence / contrast / conclusion / CTA
- speaker framing: base / punch-in / reframed / cutout
- text treatment: caption / keyword / title-card / number-card / none
- visual asset: none / photo / screenshot / product / B-roll / graphic
- layout: full-screen / speaker+asset / PIP / side-by-side / cutout composition
- reason for the visual choice

A render should not proceed until every planned visual event has an editorial reason.

## Visual hierarchy

Use this priority order:

1. Real speaker and expression
2. Concrete product/evidence/process being discussed
3. High-value explanatory text
4. Relevant image/video/screenshot
5. Decorative graphics

If two elements compete, remove the lower-priority element.

## Shot rhythm

Do not enforce a fixed number of cuts per second. Instead create a visual change when:

- the semantic subject changes
- a key claim is introduced
- an example begins
- evidence or a product needs to be shown
- a contrast or conclusion lands
- the frame has become visually stale and a meaningful reframing is available

Avoid rapid-fire changes that make a natural owner/expert video feel like an advertisement template.

## Pattern library

### Pattern A — Speaker emphasis
Speaker remains full frame; small punch-in + short keyword.

### Pattern B — Speaker + evidence
Speaker remains visible while a screenshot, product photo, or document appears beside or above them.

### Pattern C — Explain with insert
Short full-screen B-roll or product detail, then return to speaker.

### Pattern D — Cutout explanation
Speaker is masked into a simple composition with one supporting visual. Use briefly.

### Pattern E — Number / contrast card
A single large number or short contrast phrase carries the visual while the speaker continues as audio or remains in a small frame when useful.

## Anti-template rule

Never alternate mechanically between `speaker -> B-roll -> speaker -> B-roll` at equal intervals. The visual sequence must follow the meaning of the speech.

## Final review

Watch the edit with audio muted. If the visual story cannot roughly communicate the structure of the spoken argument, improve the visual plan before export.

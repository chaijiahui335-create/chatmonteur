# Anti-Low-Style Gate for Chinese Talking-Head Videos

This reference blocks common AI-looking short-video packaging mistakes.

## Hard rejects

Reject an edit if it relies on any of these as the main visual language:

- large translucent gray subtitle panels covering the lower third
- one giant caption block that repeats the full ASR transcript
- white outlined picture-in-picture boxes used repeatedly without semantic reason
- generic top-left chapter labels on every segment
- decorative horizontal rules that do not carry information
- identical picture-in-picture treatment repeated across multiple beats
- arbitrary zooms or crops with no relation to spoken meaning
- every sentence receiving the same typography treatment
- stock-looking graphics that do not match the business context
- excessive transitions between adjacent sentences

## Spoken-text hierarchy

The spoken words are the primary text source, but they must be editorially typeset.

For each semantic phrase choose one of:

1. clean two-line spoken text
2. selective keyword emphasis inside the spoken phrase
3. a short opinion phrase extracted from the spoken phrase
4. a full-screen/large statement only for a genuine hook, turn, or conclusion

Do not show all four at once.

## Layout principles

- Keep the speaker visible and expressive.
- Use negative space for text rather than covering the speaker or product.
- Prefer asymmetric compositions over centered template cards.
- Use scale, position, weight, and timing to create hierarchy; do not depend on boxes.
- Let product imagery and the speaker share the same visual system.
- When B-roll appears, it should replace or complement the relevant visual area, not sit in a decorative frame by default.

## Viral-style rhythm

A 20–30 second talking-head edit should have a deliberate sequence of visual states, for example:

hook close-up -> spoken-text emphasis -> product/detail visual -> return to speaker -> consequence/risk visual -> conclusion statement.

The sequence must follow the meaning of the speech. Do not force a fixed number of cuts.

## QC question

Before delivery ask: "If the captions and decorative graphics were removed, would the remaining cuts still make editorial sense?"

If the answer is no, the edit is decoration-driven and must be revised.

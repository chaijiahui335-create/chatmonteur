# B-roll Doctrine for Chinese Video Accounts

## Principle

B-roll is evidence, explanation, or context. It is not filler.

## Insert only when it does at least one of the following

- shows the object or process being discussed
- proves or illustrates a concrete claim
- makes a comparison easier to understand
- gives the viewer a useful visual reference
- creates a purposeful visual reset at a semantic boundary

## Selection order

1. User-provided real footage related to the topic
2. User-provided screenshots, photos, documents, product footage
3. Generated/simple graphics derived from facts already spoken
4. Relevant licensed/approved stock or web assets when available

Never invent factual evidence.

## Timing

Enter close to the spoken anchor phrase. Keep the insert only as long as it adds information. Return to the speaker when the visual has completed its job.

## Layout preference

Prefer speaker + B-roll compositions when the speaker's presence remains useful. Use full-screen B-roll only when it materially improves comprehension.

## Anti-patterns

- generic stock footage with no semantic connection
- five or more unrelated visuals in rapid succession
- repeating the same image
- covering the speaker's face
- inserting a visual solely to satisfy a fixed seconds-per-shot rule
- decorative transitions between every B-roll asset

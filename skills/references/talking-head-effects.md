# Talking-Head Visual Effects

Effects are editorial signals. Use them to clarify emphasis or prevent visual monotony, never as decoration by default.

## Reframe ladder

- Base: 100% natural framing.
- Light emphasis: small crop/push.
- Strong emphasis: tighter crop for a key phrase.
- Reset: return toward base framing after the emphasis cluster.

Avoid identical effect sequences back-to-back.

## Good uses

- punch in on a strong opinion
- slight reframe when the speaker changes topic
- side-by-side with a relevant screenshot
- picture-in-picture during a concrete example
- short masked/cutout moment for a visual explanation

## Bad uses

- zoom on every sentence
- shake effects on normal speech
- constant camera movement
- transitions between every sentence
- effects that obscure facial expression

## Semantic anchor

Every nontrivial effect should be associated with a transcript phrase, semantic segment, or visual event. If an effect cannot be explained by the edit plan, remove it.

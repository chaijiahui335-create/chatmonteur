# Viral spoken-copy layout — Chinese talking-head

## Purpose

This reference defines how a talking-head editor should turn spoken audio into editorial on-screen copy. It is **not** an ASR subtitle styling guide.

## Core rule

Audio -> transcript -> editorial copy segmentation -> emphasis words -> animated text -> matching visual.

Never render raw ASR as a continuous bottom subtitle track and call it a finished edit.

## Spoken-copy layers

1. **Spoken copy layer** — preserve the speaker's actual meaning and wording, but re-break it into short visual phrases. Do not invent claims.
2. **Emphasis layer** — extract 1–3 high-information phrases per beat. Highlight, scale, or animate only these phrases.
3. **Anchor/quote layer** — rare, large statements for hooks, reversals, numbers, or conclusions.

## Timing

- Let the spoken sentence lead; text should arrive on the word/phrase it emphasizes.
- Stagger two-line copy when useful instead of revealing a whole paragraph at once.
- Use scale/position/opacity animation for emphasis, normally 120–360 ms rather than long decorative entrances.
- Use a larger anchor only at a genuine hook, reversal, or payoff.

## Visual grammar

- Use white as the base spoken-copy color and one accent color for semantic emphasis.
- Avoid permanent labels, decorative bars, generic gray caption plates, repeated white frames, and template-like corner tags.
- Keep the speaker visually dominant unless the spoken content is being demonstrated by a product/graphic insert.
- When the speaker mentions a product detail, use the user's real product photo/video as evidence. Do not generate a generic stock substitute.
- Picture-in-picture should have a compositional reason: detail, comparison, proof, or product close-up. Vary placement and scale with the beat.

## Viral-editing principles distilled from current Chinese short-video tutorials

- Cut filler, repeated phrases, mistakes, and dead air while preserving natural breathing and meaningful pauses.
- Treat 花字 as an emphasis layer, not as a replacement for the spoken copy.
- Supplementary images/video should form an evidence chain and match the spoken point.
- Use keyframe motion and sound effects at emphasis points rather than adding transitions everywhere.
- Keep keyword effects sparse; visual hierarchy matters more than effect count.

## QC blockers

Reject the edit if:

- the main text is simply raw ASR dumped at the bottom;
- every sentence uses the same animation;
- every insert uses the same frame or position;
- a visual insert does not correspond to a spoken semantic anchor;
- large text obscures the speaker's face/product;
- the edit looks like a generic auto-caption template when the text/graphics are disabled.
